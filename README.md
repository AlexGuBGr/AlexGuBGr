# Alexander G. B. Grønning

PhD in bioinformatics. I build data pipelines, curated reference databases and tools that scientists use in their daily work.

**In progress**
- **Adipose tissue omics database**: pipelines that pull public transcriptomics and proteomics data, harmonise IDs, and serve it in an app for search, browsing and enrichment analysis
- **Peptidomics and proteomics reconciliation**: pipeline merging FragPipe, MaxQuant and PEAKS output into quality-controlled datasets
- **Language models on CPU**: how far can a small model go with retrieval-augmented generation (RAG) without a GPU?

**See some of my projects here:**
- **[PepHammer](https://github.com/AlexGuBGr/PepHammer)**: Shiny app and SQLite reference databases for matching up to 10,000 peptides at a time against known bioactive peptides. Python scripts build the databases; pytest and testthat run on every push via GitHub Actions.
- **[pepcutapp](https://github.com/scheelelab/pepcutapp)**: shows which enzymes could have produced a known peptide, from PeptideCutter cleavage sites. Tested with testthat and `shiny::testServer` in CI.
- **[MultiPep](https://github.com/scheelelab/MultiPep)**: multi-label deep learning classifier ranking peptides by predicted bioactivity. Cited 50+ times.
- **[DeepCLIP](https://github.com/deepclip/deepclip)**: deep learning model predicting how sequence variants alter protein–RNA binding. Nucleic Acids Research.
